Hello Gretio users!

Global B support for Gretio is now here and will reach general availability within the next few weeks. This includes full PID Support, controls, Diagnostic Trouble Codes, and all the features you are familiar with from the old Global A system such as regens, lightning controls, and thousands of data points / PIDs.

For those unaware: Global B (or VIP) is GM's newer vehicle architecture found on all of their new vehicles.

Global B also represents Gretio's entry into Electric Vehicles and EV-specific modules such as the "Battery Energy Control Module" and "Drive Motor Control Module (1/2)."

While there is no change to how Gretio looks with these newer vehicles, there are a large number of behind-the-scenes changes and subtle differences. For example, the connection process to Global B is different.

## iOS Changes

### Improved Connection Prompt

The new connection prompt is cleaner and more visible than the previous connect button.

![Gretio iOS connection prompt showing Not connected status and a blue Connect button](/images/83463153b2cb.png)

### Bar Gauges

You can now add colorful bar gauges to the dashboard by simply tapping on a menu

![Gretio iOS Performance dashboard with bar gauges for module voltage, engine speed and MAF sensor](/images/7bef75e5ed1a.png)

### Previous Connected Vehicles

Similar to Android, iOS now shows prior vehicles connected![Gretio iOS Vehicles list showing previously connected vehicles with VIN, last seen date and engine RPO](/images/25b42f5e8a8d.png)

## Android Changes

### Resizeable Dashboard

You can now change the underlying grid size of a dashboard to fit your specific needs better.

![Gretio Android Change Grid Size dialog setting dashboard grid columns and rows](/images/5b6238db799d.png)

### Streamline Modules Menu

The modules menu has many subtle changes. Controls are no longer locked behind a menu item.![Gretio Android BCM module card with Info, DTCs and Controls buttons](/images/1d7be295f49e.png)

And the DTC Lists are more colorful

![Gretio Android ECM DTCs list showing active codes in red with descriptions](/images/7732af161547.png)
